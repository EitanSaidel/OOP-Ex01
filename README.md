# OOP-Ex01
Problem Definition:
Given a 3D raster data matrix and a plane, the objective is to compute a 2D matrix representing the projection of p within the 3D volume
Project Scope:
1. Parsing 3D data from NRRD file.
2. Parsing a CSV file containing lists of 3D coordinates that define the slicing planes.
3. Implementing an algorithm to map 3D coordinates to a 2D image matrix.
4. Optimazation to achieve the required FPS.
5. Video generation.
